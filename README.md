# cresflo-backend

Express + TypeScript backend scaffold with a clean `app.ts` and `server.ts` setup.

## Structure

```text
src/
  app.ts
  server.ts
  controllers/
    health.controller.ts
  middlewares/
    error-handler.ts
    not-found.ts
  routes/
    health.routes.ts
    index.ts
```

## Install dependencies

```bash
bun install
```

## Build

```bash
npm run build
```

## Start the server

```bash
npm run start
```
